Install

Run without installing

npx github:Blackman99/undomap            # map the current directory
npx github:Blackman99/undomap ~/code     # or any directory

Requires Node.js 18.17+ and git on PATH. Without git, undomap still runs but grades everything as outside git and tells you so. The package is one bundled file with no runtime dependencies.

Install the command

npm install -g github:Blackman99/undomap
undomap --version

Or download undomap-0.1.0.tgz from GitHub Releases and run npm install -g ./undomap-0.1.0.tgz. It isn't on the npm registry yet. Once it is, npx undomap will work too.

Platforms

OSSnapshot probe
macOStmutil destinationinfo, listlocalsnapshots, and isexcluded for each fragile path
Linuxfindmnt for the mount, then snapper (.snapshots), ZFS (.zfs/snapshot) and Timeshift
WindowsShadow copies are reported as unknown, because vssadmin needs an admin shell

Every platform also gets the read-only cloud-sync probe (iCloud Drive, Dropbox, OneDrive, Google Drive). It reads client config files, lists running apps (ps / tasklist) and reads the Dropbox ignore attribute (xattr, getfattr from the attr package on Linux, an NTFS stream on Windows).
